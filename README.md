# Summer Olympic 🏅

폰 하나로 여럿이 돌려 가며 즐기는 여름 올림픽 미니게임 모음.
설치 없이 안드로이드 크롬에서 바로 실행되는 웹 앱(PWA)입니다.

## 플레이하기

### 안드로이드 앱 (APK)
1. 폰 크롬에서 [최신 릴리스 페이지](https://github.com/grehful/summerolympic/releases/latest) 를 열고 Assets 의 `summerolympic-버전.apk` 를 누르기
2. 받은 파일을 눌러 설치 — "출처를 알 수 없는 앱" 경고가 나오면 **설정 → 이 출처 허용** 후 다시 설치
3. 인터넷 없이 실행됩니다

새 버전으로 다시 빌드: `./android/build.sh` → `android/build/summerolympic.apk` (같은 키로 서명되어 덮어쓰기 설치 가능)

### 웹으로 실행
1. 저장소 **Settings → Pages**에서 *Deploy from a branch* → `main` / `/ (root)` 선택
2. 폰 크롬에서 `https://grehful.github.io/summerolympic/` 접속
3. 크롬 메뉴 ⋮ → **홈 화면에 추가** → 앱처럼 전체화면 실행 (한 번 열면 오프라인에서도 동작)

### 멀리뛰기 규칙
- 시작 전에 인원(1~8명)과 1인당 시도 횟수(1/3/6번)를 정합니다.
- 화면에 시속(km/h)과 각도(°)가 소수점 한 자리까지 표시됩니다.
- 발판의 빨간 선을 넘으면 파울. 기록은 빨간 선부터 착지 지점까지 (cm 아래 버림).
  너무 일찍 뛰면 그만큼 손해예요.
- 각도가 높을수록 도약 속도가 줄어서, **약 20°** 근처가 가장 멀리 나갑니다.
- 순위는 최고 기록 → 두 번째 기록 순으로 비교합니다.

### 3단 뛰기 규칙
- 홉은 멀리뛰기처럼: 점프 구간에서 누르고 있으면 각도 상승, 떼면 도약. 발판 선을 넘으면 파울.
- 공중에서 착지할 곳에 원이 줄어듦 → 땅에 닿는 순간 점프 버튼. 오차 0.06초 이내 '퍼펙트'(속도 97% 유지), 0.12초 '좋아요'(92%), 0.2초(84%), 0.35초(72%), 그 이상 늦으면 리듬이 끊겨 파울.
- 누르고 있는 동안 각도가 오르지만 땅을 딛고 있는 만큼 속도가 빠짐 → 각 도약 15~20°가 좋음.
- 세 번째 점프가 모래판(선에서 8m~)에 떨어져야 기록. 시속·각도 소수점 한 자리, 결과에 홉/스텝/점프 거리와 리듬 판정 표시.

### 100m 달리기 규칙
- 인원(1~8명), 1인당 레이스 수(1/2/3번). 시속(km/h) 소수점 한 자리, 기록은 1/100초까지.
- 총소리 전에 누르거나 총소리 후 0.1초 안에 누르면 부정 출발. 2번이면 실격.
- 탭마다 스태미너가 줄고 시간이 지나면 다시 찹니다 (초당 4번 정도 연타까지는 줄지 않음).
  25% 아래로 내려가면 힘이 빠지기 시작하고, 0%가 되면 30%까지 회복될 때까지 지쳐서 느려집니다.
- 90m 지점(남은 10m)에서 스태미너가 100%로 채워집니다.
- 다른 선수들의 최고 기록이 반투명한 유령 선수로 옆 레인에서 같이 달립니다.

### 양궁 규칙
- 70m, 122cm 과녁 (10점~1점, 정중앙 X). 3발 = 1엔드, 엔드 수 2/4/6. 한 발 제한 시간 20초 (넘기면 0점).
- 조준점은 늘 흔들립니다. 당긴 지 1~4초(호흡 막대 초록 구간)가 가장 안정, 그 뒤로는 팔이 지쳐 점점 커지고 8초면 활이 풀립니다.
- 바람은 한 발마다 바뀌고(0.3~4 m/s, 소수점 한 자리 표시) 조준하는 동안에도 조금씩 변합니다. 1 m/s ≈ 점수 한 칸 반 밀림.
- 조준 위치는 다음 화살·엔드에도 이어집니다. 순위: 총점 → 10점 개수 → X 개수.

### 투포환 규칙
- 원을 빠르게 그릴수록 파워 상승 (초당 2.2바퀴면 최대). 2바퀴는 돌아야 몸이 다 감기고, 3바퀴를 넘기면 서클 밖으로 나가 파울.
- 손을 떼기 직전 0.1초 동안 손가락이 움직인 방향이 투척 각도(소수점 한 자리), 튕기는 속도만큼 보너스. 약 38~42°가 가장 멀리 나감.
- 너무 천천히 떼면 "놓침", 뒤로 던지면 파울. 기록은 스톱보드부터 (cm 아래 버림), 노란 선 = 세계기록 23.56m.
- 순위: 최고 기록 → 두 번째 기록 순.

### 창던지기 규칙
- 같은 발을 두 번 누르면 삐끗 (속도 30% 손실). 시속(km/h)·각도(°) 소수점 한 자리.
- 화면에 손가락을 대는 순간 발을 디디고(위치 고정), 손을 떼기 직전 0.1초의 방향이 각도·속도가 팔 힘.
- 투척 속도 = 기본 + 달리던 속도 + 팔 힘, 순풍/역풍(±2 m/s) 반영. 35° 안팎이 최고, 45° 넘으면 꼬리부터 떨어져 파울.
- 던진 뒤 멈추는 거리(달리던 속도에 비례)가 트랙에 '멈추는 곳'으로 표시됨 → 파울 라인을 넘으면 파울. 기록은 파울 라인부터. 잔디에 5m마다 거리 표시.

### 높이뛰기 규칙
- 속도 게이지의 초록 구간(시속 25.2~28.8km)이 최고. 느리면 높이가 안 나고, 너무 빨라도 손해. 도약 표시(±1.5m)에서 멀수록 손해.
- 공중: 엉덩이가 바를 지나기 직전에 누르고(젖히기), 다리가 지날 때 떼기(차올리기). 어깨·엉덩이·다리 중 하나라도 바보다 낮으면 실패.
- 시작 높이 1.50/1.80/2.00m, 2.00m까지 10cm, 2.30m까지 5cm, 그 뒤 3cm씩 상승. 높이마다 3번, 3번 실패하면 탈락. 모두 탈락하면 끝.
- 순위: 최고 성공 높이 → 그 높이 실패 수 → 전체 실패 수.

### 역도 규칙 (용상)
- 1인 3시기, 매 시기 무게를 직접 정함. 무게는 내릴 수 없음 (성공하면 +1kg 이상, 실패하면 같은 무게 이상).
- 클린 → 저크: 왔다 갔다 하는 바늘을 초록 구간에서 탭. 저크는 더 빠르고 좁음. 무거울수록 바늘이 빠르고 구간이 좁아짐.
- 버티기: 머리 위 바벨이 거꾸로 세운 막대처럼 점점 기울어짐 → 내려간 쪽 버튼을 눌러 3초 버티면 심판 흰 불 3개 '굿 리프트'. 14° 넘게 기울면 실패. 저크가 부정확할수록 처음부터 기운 채로 시작.
- 순위: 성공한 최고 무게 → 실패 횟수.

### 트램폴린 규칙
- 닿는 순간 탭 판정: 퍼펙트(0.06초 이내) +0.9m, 좋아요 +0.5m, 아쉬워요 +0.1m, 늦음/빠름 −0.5m, 놓치면 높이 55%로. 최고 8.5m.
- 공중에서 원판에 원을 그린 만큼 몸이 회전 (시계 방향 = 앞, 반대 = 뒤). 닿을 때 발이 아래에서 40° 넘게 벗어나면 넘어져 루틴 종료.
- 준비 바운스 3번 → 기술 10개. 난도 D: 1회전 0.5, 2회전 1.2, 3회전 2.0, 4회전 3.0. 실시 E: 10점에서 타이밍·착지 각도 감점, 넘어지면 −2. 체공 점수 = 체공 시간 × 0.6.
- 높이 뛸수록 체공 시간이 길어 더 많이 돌 수 있음. 순위는 최고 루틴 점수.

## 🏅 올림픽 모드
메인 화면의 **올림픽 모드** → 인원·종목 수(3/5/9) → 선수마다 나라 선택(OECD 38개국, 겹치기 불가) → 종목을 차례로 치르며 메달 경쟁 → 폐회식.

- 나라마다 종목별 실력 ★1~5 (`shared/js/countries.js`). ★1은 보너스 없음, ★5가 최대 보너스.
- ★5 기준 보너스: 달리기 종목은 연타 가속 +8%·최고 속도 +4%(100m는 스태미너 소모 −15%), 투포환·창던지기 힘 +7%, 양궁 흔들림 −35%, 높이뛰기 도약 +5%·적정 속도 폭 넓게, 역도 바늘 느리게·구간 넓게·덜 흔들림, 3단 뛰기·트램폴린 타이밍 판정 +40%.
- 메달 순위: 금 → 은 → 동 → 순위 점수 순. 진행 상황은 자동 저장돼서 앱을 껐다 켜도 이어서 할 수 있음.
- **🏁 올림픽 끝내기**: 일정 화면, 매 차례 안내 화면, 종목 결과 화면에 있음. 누르면 확인 없이 바로 끝나고 메인 화면으로.
- 종목 페이지는 `?olympic=1` 로 열리면 `shared/js/olympic.js` 를 통해 설정 화면 없이 바로 시작하고, 끝나면 결과를 저장한 뒤 `olympic/` 로 돌아옴.

### 새 종목 추가하기
1. `games/<종목>/index.html` 생성 — `shared/` 의 CSS/JS를 불러와서 `SO.setupPlayers(...)`로 인원 설정 화면 재사용
2. `shared/js/games.js` 에 항목 추가 (`ready: true`)
3. 올림픽 모드에 넣으려면 `olympic.js` 의 `EVENTS`/`ORDER`, `countries.js` 의 ★ 칸, 종목 JS에 `applyBoost`/`onFinal` 연결
4. `./android/build.sh` 로 APK 다시 빌드 → `apk/` 에 복사

## 로컬에서 실행

```sh
python3 -m http.server 8000   # → http://localhost:8000
```
PC에서는 스페이스/→ = 달리기, ↑ 누르고 있기 = 점프.
